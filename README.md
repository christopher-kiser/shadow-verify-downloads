# Shadow Verify development downloads

Get the desktop preview from https://appreciated-library-784500.framer.app/download . No GitHub account is required to download these files.

This repository distributes application files only. The application source repository and customer workspace data remain separate.

- Windows x64: Setup installs for the current user and creates Start menu and desktop shortcuts. Close the app before running Setup again or uninstalling.
- macOS Apple Silicon / Intel: unsigned development archives. These builds have not been executed or qualified on a Mac. Use the browser workspace while Mac qualification is in progress; do not bypass operating-system protections.
- The preview requires internet and workspace access. Downloading does not grant access to a workspace or connect an AWS account.
- These builds are unsigned, have no automatic updates, and are not a production release. Current verification examples are MOCKED.

Checksums are supplied with each release. Third-party license notices are included in the application packages.
